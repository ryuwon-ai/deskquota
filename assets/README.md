# DeskQuota brand asset

`deskquota-hero.png` is an original conceptual illustration generated with the
built-in image generation tool on 2026-09-15. It represents request scheduling;
it is not a photograph of a hardware product or a screenshot of a working UI.
No reference images or third-party logos were used. The original generated
pixels were copied into this repository without edits.

## README design references

The README uses a short positioning statement, an early getting-started path,
and measurements with their scope attached. References were read for structure,
not copied for their performance or compatibility claims:

- [Pi](https://github.com/earendil-works/pi/blob/f3c672245d25ef2283ffc0d9cdec8a5482651103/README.md): concise introduction and documentation navigation.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent/blob/3b45681c25a880477a2a806cdebe91d2f1bfe9ce/README.md): banner and visible setup path.
- [ECC](https://github.com/affaan-m/ECC): locally installed 2.2.1 README; visual entrypoint and grouped links.
- [Ponytail](https://github.com/DietrichGebert/ponytail): locally installed 4.9.0 README; clear proposition and bounded measurement claims.

## Generation prompt

```text
Use case: ads-marketing.
Asset type: premium wide GitHub README hero banner for DeskQuota, a tiny native local LLM quota gateway used on a personal computer at work or at home.
Primary request: create an original, sophisticated editorial brand illustration, 2400 x 960 landscape composition. The aesthetic is warm architectural product design, restrained and precise, not a generic AI dashboard.
Scene: a quiet personal desk rendered as a sculptural still life on warm ivory paper. On the right half, a small matte graphite desk appliance with three narrow orderly slots, beside a minimal closed notebook and a thin desk surface. A few translucent amber and muted teal rectangular tokens of different lengths approach from separate lanes and leave neatly aligned through the small appliance. This is a conceptual metaphor for sharing limited requests, not a real hardware product or a software screenshot. Soft daylight, subtle tactile grain, brushed aluminum, warm shadows, abundant negative space.
Typography on the left, large and beautifully typeset, exact text only:
"DeskQuota"
"Your LLM quota,"
"managed at your desk."
The main wordmark must be dark ink, easily readable at GitHub width. Tagline smaller but clearly readable. Keep generous outer margins. Use only the three text lines above. No badges, no benchmark figures, no third-party logos, no other words.
Composition: roughly left 50 percent typography, right 50 percent sculptural illustration. All objects remain subordinate to the wordmark. Refined Swiss editorial layout with subtle Japanese desk stationery sensibility. Flat off-white background that will look good inside GitHub's white or dark page. Minimal rust-orange accent, graphite and soft teal. Avoid neon, purple gradients, cyberpunk, robot faces, stock office photos, shiny sci-fi rings, heavy shadows, busy connectors, watermarks. Deliver a polished finished banner.
```
